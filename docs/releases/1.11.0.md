# MFG Unlock 1.11.0 — Performance overlay, RenoDX DLSS and "DLSS 5" addons, Dynamic MFG in more games

Fixes from two weeks of reports on 1.10.1, and a performance overlay. The games named were tested by their reporters, not by us, unless said otherwise.

## Performance overlay

An on-screen display drawn over the game, also with the ReShade menu closed. It is off by default: turn it on with **Shift+F10** or under **General → Performance overlay**.

- **Minimal:** the output frame rate, and the game's own frame rate when frames are generated ("191 FPS (game 48)").
- **Standard** (the default when on): adds the frame time average, 99th percentile and maximum, the 1% and 0.1% lows, hitches over 50 ms, and the frame generation method with its status in words (DLSS-G's multiplier and status flags, why XeMFG DLSS-G is not generating, XeMFG's state).
- **Full:** adds a frame time graph, PC latency and its 95th percentile, GPU time, the display rate and video memory against the budget.

Position, size, background opacity and the shortcut are in its section; changes apply at once. A game in which the overlay is never turned on pays nothing for it: ReShade draws its UI every frame only once an addon asks to draw, so the overlay asks the first time it is turned on.

## Add frame generation

- **With RenoDX's DLSS addon (Lies of P, Hi-Fi RUSH).** Frame generation stopped after a few seconds with "Compatibility issue" (DLSS-G: Reflex not detected). RenoDX's DLSS addon creates the game's swap chain on MFG Unlock's Streamline, and MFG Unlock then put a second Streamline swap chain under it, so DLSS-G saw two presents per frame. Now there is one, and frame generation paces from it. Keep RenoDX DLSS on. Reproduced and fixed in an automated test; confirmed on Lies of P by its reporter only without the addon so far.
- **The game's own Reflex** is left alone. `[DLSSG] HostGameReflex=0` holds it back while MFG Unlock hosts Streamline, if a game ever needs it (not needed for the games above).
- **The Medium, Hi-Fi RUSH (Unreal Engine games).** DLSS-G reported "GetCurrentBackBufferIndex not called" at every frame (status 0x10): these games never call it on Streamline's swap chain. MFG Unlock makes the call before each Present. This should also let XeMFG DLSS-G generate in The Medium, where it saw a history reset almost every frame; the support report now counts the resets the game itself sends (`game resets`) to tell them apart.
- **Another addon's NGX hooks** (a "DLSS 5" addon in Shadow of the Tomb Raider): when another addon removed its hooks from NVIDIA's NGX runtime, ours went with them and DLSS Super Resolution was never seen again. The hooks are checked once a second and installed again.

## XeMFG DLSS-G

- **"DLSS 5" addons that work at Present** (Lies of P): with **free NVIDIA's unused memory** on (the default), MFG Unlock answered frame generation's creation itself, so an addon hooked into NGX never saw frame generation and its Present mode waited forever. When another module hooks NGX, the option now stands aside for the session and NVIDIA's feature is created as before 1.10.0. The panel names the addon.

## Forced DLSS frame generation (Streamline games without it)

- **A game without `sl.dlss_g.dll`** (Ninja Gaiden 4): MFG Unlock lends its own plugin when it is for the same Streamline version as the game's, from a folder of its own.
- **A plugin for another Streamline version** (a 2.14.16 `sl.dlss_g.dll` copied beside Ninja Gaiden 4's 2.13): it is no longer used, which crashed the game. Use one matching set of `sl.*.dll`; the log, the support report and the panel say so.
- **A game whose swap chain bypasses Streamline** (Ninja Gaiden 4 without RenoDX DLSS): after 600 frames the log and the support report say so and name what works (an addon that moves the swap chain into Streamline, such as RenoDX DLSS).

## NVIDIA Dynamic MFG

- **Games that never ask the runtime about it** (Microsoft Flight Simulator 2020): the panel stayed at "the runtime has not answered the Dynamic support query yet", at a fixed multiplier. MFG Unlock now asks itself, at most once a second, until the runtime answers. Toggle Frame Generation off and on in the game once after that, as the panel says. Not yet confirmed by the reporter.

## HUD fix

- **Unreal Engine games** (Hi-Fi RUSH): Unreal's tonemap pass is a single indexed triangle, which the fix did not recognize, so it never found the image before the HUD.
- When the fix finds nothing for 600 frames, it records 3 frames of `HudTrace` on its own, so a report already has what the next fix needs. Repeated lines are folded, so whole frames fit.

## Reliability

- **"The last session may have closed unexpectedly"** appeared after a normal exit in games that close with `TerminateProcess` (Unreal games, launchers, anti-cheats, Steam's Stop). A session counts as ended cleanly once the game started closing (its last swap chain gone, or `TerminateProcess` on itself), unless the crash record says otherwise.
- **Hang record.** When the game stops responding inside something MFG Unlock watches (starting Streamline, creating the swap chain, Present, NGX feature creation) for 15 s, `MFGAdaUnlock-hang.txt` is written beside the game with where it is stuck. With `[Diagnostics] CrashDump=1`, a dump file too. **Save support files** includes both. For Monster Hunter Wilds, which stopped responding at start in one report.
- **Support report:** `other_hooks=` names other addons hooked into NGX, Streamline or NVAPI (RenoDX DLSS, "DLSS 5" addons, GITC Uplift, OptiScaler); `streamline_host` counts the Streamline swap chains and, when the game's folder has its own `sl.interposer.dll`, says which copy is in use.

## Vulkan

- The notice for FP16 (scRGB) HDR swap chains, which DLSS-G does not support, also appears for Vulkan games with Add frame generation.

## Tested

- NVIDIA's Streamline Sample and an NGX-only test app, Add frame generation with and without a swap chain made on Streamline's factory as RenoDX DLSS does (automated; the second fails with 1.10.1's addon exactly as the reports did).
- Cyberpunk 2077, XeMFG DLSS-G at 4x: the performance overlay.
- Lies of P, Add frame generation without RenoDX DLSS: generating, no "Compatibility issue" (reporter).

## Known limits

- Zelda: Ocarina of Time (Vulkan port) with a "DLSS 5" addon in Present mode: the addon sees no frame generation, and nothing on MFG Unlock's side explains it yet.
- Kingdom Come: Deliverance II with a second set of Streamline files in the game folder: DLSS leaves the game's menu. Remove the game folder's six `sl.*`/`nvngx_dlssg` files and keep `MFGUnlock-Streamline`; frame generation there still needs logs.
- Metro Exodus in HDR: the crosshair still repeats with the HUD fix.
- Games whose own HDR uses FP16 (scRGB): no frame generation through DLSS-G (NVIDIA's limit).
