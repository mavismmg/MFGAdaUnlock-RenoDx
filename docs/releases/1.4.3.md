# MFG Ada Unlock 1.4.3 — Continuous Border Stability

This update builds on 1.4.2 with smoother border-confidence transitions during diagonal movement. It targets abrupt changes near screen edges when motion crosses between horizontal and vertical dominance, particularly around 45 degrees.

### Image stability

- **Continuous border-axis blending.** Horizontal and vertical border treatments now blend smoothly, reducing sudden changes in border confidence as the motion direction changes.
- **Protected corners and native weighting.** Each axis retains its perpendicular-edge protection, structural candidate checks and native warp-weight anchor. The existing subpixel motion transition is preserved.
- **Local processing.** The active path uses Local Stable geometry and V2 Compatibility inpaint, without additional texture reads or confidence-history buffers.

### Documentation and build reporting

- Updated documentation describes the active release behavior and separates temporal-history research from the local path.
- Build manifests identify the variant, source and binary hashes, and embedded payload inputs for reproducible validation.

### Validation

All **32 automated tests passed**. The emitted border program passed **25,796 synthetic GPU cases in both motion directions**, with zero mismatches within the defined tolerance. Assembly and driver JIT validation retained **48 warp registers**; the geometry kernel remains at **40 registers**, with zero stack, spills or local memory.

Initial in-game feedback has been positive. Comparative FPS, frame-time and latency benchmarks are still pending; these checks do not establish a performance gain or universal artifact reduction.

### Installation

Close the game, replace the previous MFG Unlock addon, keep only one addon installed, and restart. Your existing configuration can be retained; no INI reset is required.

The border change requires the V3 profile with **Motion-directional border taper** enabled. Exact provider validation and native fallback remain in place.
